# Text Mining Projects

Repository to store projects related to our Text Mining Course at ITESO University, Fall 2025. The projects were worked on by **Sofía Maldonado García**, **Viviana Toledo De la Fuente** and **Diana Denise Valdivia Vargas**

- **1Movies_Sentiment_Analysis** is a sentiment analysis classification for IMDB reviews. It compares Logistic Regression, Naive Bayes and SVC to classify reviews, using an n-gram count vectorizer to extract text features.

- **2Skipgram&CBOW** uses CBOW and Skipgram algorithms to generate embeddings of a corpus about Anarchy on Wikipedia. It also visualizes both approaches via UMAP and t-SNE.

- **3Sentiment_Analysis_2_Electric_Boogaloo** is an improvement upon our first sentiment analysis project, aimed at identifying Anti-LGBT sentiment in tweets. It compares different methods to extract features for text classification: 
    - TF-IDF for a Logistic Regression
    - TF-IDF coupled with POS-NER tagging for a FNN
    - Embeddings and classification using BERT
    - POS-tagged n-grams coupled with a CountVectorizer for a Logistic Regression  

- **4Hugging_Face_tut** is a tutorial for didactic purposes on Model Sharing, Inference & Deployment in Hugging Face

- **5CookingMama** is a generator of cooking recipes based on user input, using a GPT-2 model. It features an interface using gradio to try out the model.
